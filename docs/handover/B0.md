- Pemeriksaan Compose menunggu seluruh service sehat; PostgreSQL memakai pgvector dan migrasi selesai. Integration test memverifikasi role API/worker, batas akses worker pada tabel fondasi, dan akses update untuk `job_stages`.

- Baseline release berhasil didaftarkan dan diaktifkan dengan `empirical_verification=false`.
- Outbox smoke operation mencapai status `succeeded`.
- Enam Playwright smoke lulus: login dosen sintetis, pesan kredensial generik, penolakan request login lintas origin, pencabutan session saat logout, lebar layar 360/768/1440 tanpa overflow horizontal, serta pembatasan admin tanpa enrollment dari course dan roster.
- Host pytest melaporkan 16 passed dan 1 skipped; test PostgreSQL yang di-skip pada host dijalankan terpisah di Compose dan lulus 1 passed. Ada satu warning deprecation dari integrasi `starlette.testclient` dengan `httpx`.

## Catatan operasional

Development memakai data sintetis dan credential acak yang tersimpan dalam `.env*` ter-ignore. File tersebut tidak dicetak atau disimpan dalam source control. Pada pemeriksaan ini proxy tersedia di `http://127.0.0.1:3100`; database, broker, dan storage tidak dipublikasikan ke host. S3Mock hanya untuk development/test; production memerlukan bucket privat yang dikonfigurasi operator.

Tidak ada provider live atau biaya eksternal. Mock provider memakai fixture berlabel simulasi dan adapter live ditolak sebelum akses jaringan. Baseline release tidak mengklaim parser, model live, atau efektivitas metode telah diverifikasi.
