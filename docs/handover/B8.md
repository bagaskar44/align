## Bukti B8 yang dihasilkan

- `services/api/src/align_api/evaluation.py` menyediakan evaluasi metrik/policy offline dengan identity target/kategori/context numerik yang exact, denominator eksplisit, duplicate sebagai FP/duplicate burden, zero-denominator `NA`, cluster bootstrap per assignment yang distratifikasi course, source/document/anchor/support coverage, failure/modality breakdown, dan pemisahan mode synthetic/institutional. Cost tidak dilaporkan lengkap bila usage pending/unknown, ledger hilang, atau scope bukan end-to-end; report mengeluarkan cost per bundle, correctly supported finding dan approved feedback hanya jika denominator/cost lengkap.
- Policy gate memerlukan support threshold master, tiga run nyata dengan ID/hash/subset yang sama dan critical invariants bersih, paired manifest hashes dengan hanya faktor yang diuji berubah, finding-level human rating terikat codebook, dua-rater institutional gold, settled end-to-end cost, dan pemeriksaan ledger sebelum eligibility. CLI B8 tidak memverifikasi ledger database sehingga tidak dapat menerbitkan eligible melalui command offline ini. Mock/synthetic tidak dapat mengaktifkan optimasi.
- `scripts/openapi_contract.py` membuat `docs/api/openapi.json` dan typed operation/schema/path contract web. Pemeriksaan memvalidasi snapshot server, method/path client, serta referensi route literal pada consumer web. Health provider internal tidak dimasukkan ke API web publik.
- CLI existing `align parser benchmark`, `align evaluate robustness`, dan B8 `align evaluate metrics|policies` menulis laporan JSON/Markdown. Robustness report kini secara eksplisit memisahkan compiler fidelity, executor variation, format variation, source corruption dan repeat dependence; kasus yang tidak dijalankan berstatus `not_run`, bukan pass. `research/templates/` memuat DSRM/iteration, codebook, dataset/partition, baseline-ablation, demo, policy dan robustness templates; template kosong bukan input evaluator yang sah.
- README dan `.env.example` diselaraskan dengan prosedur macOS dan 87 Settings field; file role/database-only di `.env.example` tetap dicatat terpisah. `scripts/verify-macos-clean.sh` membuat snapshot source tanpa `.env`, `.venv`, cache, `node_modules`, atau `.vscode`; menyediakan subnet Docker uji karena default address pool host penuh, tanpa menghapus network/volume lama.
- Dua demo B8 di [Sistem Informasi](../../research/demos/B8-sistem-informasi.md) dan [Manajemen](../../research/demos/B8-manajemen.md) memuat ID dan versi runtime, manifest/file hashes, review/evidence/annotation/feedback/publication IDs, hasil student export dan batas status parser. Enam screenshot tiga viewport disimpan di direktori report; gambar hanya menampilkan fixture sintetis.
