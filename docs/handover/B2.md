## Pekerjaan B2 yang masih pending

- Jalur rubrik perlu memakai parser bersama B1 dan menghasilkan candidate/descriptor yang ditinjau dosen. Saat ini hanya original file privat/hash-bound; tidak ada retrieval/parse bundle rubrik.
- Generator sekarang excerpt instruksi, bukan adapter draft criteria semantik/configured. Ia sengaja tidak mengklasifikasikan kewajiban.
- UI belum menyediakan editor bertipe untuk criteria/spec/NumericPolicy, tampilan berdampingan derivation dan source span code point, maupun kontrol visual applicability, grounding/roles, evidence, DAG dan resolution.
- Belum ada Playwright end-to-end B2, fixture semantic-negative menyeluruh, race test dua dosen atas approval/publish, atau bukti DB concurrency untuk seluruh invalidation. Integrasi yang lulus memvalidasi subset aturan utama.
- Shared acceptance yang memang dimiliki B3–B8—misalnya late submission, executor/retrieval semantics, robustness/equivalence dan pemeriksaan mahasiswa—tetap di tahap pemiliknya. Keberadaan schema awal di B2 tidak dihitung sebagai gate mereka.

Status rinci per requirement ada pada [overlay traceability B2](../../requirements_traceability.md#overlay-implementasi-b2). Dokumen implementasi menandai setiap acceptance yang belum dibuktikan sebagai pending. Berhenti pada B2; jangan mulai submission/viewer B3 sampai instruksi tahap berikutnya.
