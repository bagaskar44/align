## Audit paid consumers

Audit dilakukan sebelum penyambungan ledger. Semua network call provider berbayar berakhir di satu endpoint `urllib.request.urlopen` pada `packages/domain/src/align_domain/providers.py`, dengan URL tetap API OpenAI. Caller yang ditemukan: B1 context extraction (`services/worker/src/align_worker/context_provider.py`), B2 assignment/spec drafting (`services/worker/src/align_worker/drafting.py`), B5 analysis/embedding (`services/worker/src/align_worker/executor.py`), dan feedback generation (`services/api/src/align_api/reviews.py`, diproses lewat `services/worker/src/align_worker/feedback.py`). `assignments.py` hanya memasukkan release scope ke job drafting. Search juga memeriksa `requests`, `httpx`, `urlopen` dan adapter construction di `packages/`, `services/`, serta `scripts/`; tidak ditemukan provider endpoint berbayar kedua. `scripts/prepare-parser-resources.py` mengakses registry parser tetap, bukan paid model consumer.

Setiap caller live mengirim konteks finansial ke `OpenAIResponsesProvider` dan `WorkerPaidCallLedger`; provider menolak sebelum I/O jika flag, active live release, verified rate, bounds atau ledger tidak lengkap. Reservation dibukukan dalam transaksi lebih dahulu, network berjalan tanpa memegang transaksi DB, lalu hasil disettle atau liability tetap ditahan untuk reconciliation. `PAID_CALLS_ENABLED` default `false`; tidak ada key yang dapat melewati ledger. Tidak ada panggilan provider/biaya nyata pada tahap ini.
