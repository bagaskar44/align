## Perubahan terhadap baseline dan hasil audit

Catatan sebelumnya terlalu luas pada klaim auth/context dan terlalu sempit pada batas parser. Audit kode menemukan password 128 byte alih-alih karakter, session saat ini ikut dicabut saat ganti password, cursor belum berfungsi, UI belum polling, manifest parser belum terikat, checkpoint PDF masih seluruh file, lease expired dilepas tanpa bukti child mati, dan coverage runtime isolasi/failure belum cukup. Seluruh koreksi berikut tetap dalam B1:

- Auth memeriksa body sebelum hashing, menerima 12–128 code point dengan batas UTF-8 512 byte, merotasi bearer/CSRF session saat ini, mencabut session lain, serta menserialkan login/reset/deaktivasi. Admin aktif terakhir dilindungi dari demosi bersamaan.
- Idempotency juga mengunci key sebelum row pertama ada. Revision, foreign source, course lineage, validasi hash/anchor dan immediate revocation diperiksa di backend.
- Upload/download privat memverifikasi byte/hash secara streaming sebelum respons unduhan; asset belum validated tidak dapat dilihat. Preflight SAX menolak DTD/entity dan memeriksa batas OOXML tanpa menyimpan text tree. PDF encrypted/101 halaman, spoofed MIME dan gambar di atas 25 MP ditolak sebelum parsing.
- Migration tambahan `0003_b1_provenance_guards` mengunci writes anak pada parent context, menguatkan immutability link/artifact/source unit/evidence, memeriksa integritas evidence, dan melarang worker INSERT/approve ContextVersion. Migration 0001/0002 tidak ditulis ulang.
- UI memisahkan draft baru/editor, memakai cursor, polling dan notifikasi revisi baru tanpa menimpa edit yang belum disimpan; konflik dapat dipilih/dikoreksi manual dengan alasan. Field mempunyai cuplikan sumber/anchor dan unduhan berizin. Total evidence serta batas tampilan 500 ditampilkan; sampel unit unresolved dibatasi 50 secara eksplisit.
- Parser tetap native python-docx/OOXML untuk DOCX dan Docling untuk PDF/gambar. Root/container/page asli diinventaris sebelum child dijalankan; PDF memakai checkpoint satu halaman. Job/artifact/evidence/checkpoint mengikat manifest, hash sumber, opsi, model dan profil. EXIF diproses pada turunan sementara, dengan transform dan bbox dipetakan ke pixel original.
- Heartbeat memperbarui lease Redis/DB; fence diperiksa sebelum commit; cleanup menghentikan process group sebelum melepas reservation. Parent-death signal Linux menghentikan direct child. Expired lease mengarantina node; expiry bukan bukti proses mati.
- Adapter `MockProvider.extract_fields` sekarang menghasilkan `ContextFieldOutput` tertutup. Simulasi hanya mengembalikan kandidat teks berlabel dari parser dengan source reference yang sama; ini bukan model yang memahami dokumen bebas. Scope/call/manifest/policy/output/schema diperiksa sebelum merge. Refusal, invalid output, unavailable/off dan cap menghasilkan keterbatasan serta jalur manual. `PROVIDER_MODE=off` didukung; live tetap diblokir sebelum network. Satu mock call per assembly, nol paid calls; batas job memakai cap normatif 3 text/vision calls, 2 vision, 20k/4k token dan USD0.05. Simulasi memakai batas byte konservatif, bukan klaim tokenizer/model live telah diuji.

Arsitektur service dan kontrak endpoint publik tetap mengikuti master. Ada payload tambahan untuk processing/inventory/truncation, schema output mock, dan mode off sesuai kebutuhan B1. Keputusan lokal serta pengecualian lockfile dijelaskan di [TD-B1-01–06](../technical-decisions.md).

## Lingkungan dan resource yang benar-benar dipakai

Verifikasi memakai Mac ARM64, Docker Desktop Linux/aarch64, checkout uji di direktori sementara terisolasi, project Compose `align-b1-audit`, origin `http://localhost:3102`, env privat dan named volume sendiri. Source kandidat disalin tanpa instalasi ignored atau database development. Toolchain/cache berasal dari prefix dan cache uji terpisah yang dibuat untuk pembuktian setup bersih; instalasi frontend memakai frozen lockfile.

Pengguna mengizinkan alokasi Docker Desktop dinaikkan menjadi 12 GiB (`MemoryMiB=12288`) dan restart. Engine melaporkan `12526637056` byte, sekitar 11,67 GiB. Untuk matrix heavy, web/proxy/worker umum/scheduler stack uji dijeda. Setelah konfirmasi 0 job/operation pending, pengguna juga mengizinkan worker/scheduler development dijeda sementara lalu dipulihkan. API/web development dan kedua database tetap tersedia selama jeda. Dua stack lengkap pada VM ini tidak selalu menyediakan 9 GiB RAM host yang dibutuhkan admission. Sebelum matrix final tersedia host `10035912704` byte dan cgroup `9428078592` byte (masing-masing sekitar 9,35 dan 8,78 GiB).

## Prosedur ulang

Dari checkout bersih ikuti [setup macOS](macos-local-setup.md): sediakan Docker, toolchain, bootstrap env privat, install frozen, role initialization, migration, startup, seed dan verifikasi login. Jangan menyalin ignored tools/env/database dari development.

```sh
source scripts/macos-env.sh
bash scripts/dev-macos.sh up
bash scripts/dev-macos.sh seed
bash scripts/dev-macos.sh verify
bash scripts/dev-macos.sh integration
bash scripts/dev-macos.sh parser-up
bash scripts/dev-macos.sh parser-integration
ALIGN_WEB_BASE_URL=http://localhost:3000 corepack pnpm --dir apps/web test:e2e
```

Untuk isolasi gunakan checkout/env tersendiri dan `ALIGN_COMPOSE_PROJECT`/`ALIGN_HOST_PORT` sebelum bootstrap. Parser integration memerlukan model build serta RAM admission nyata; alokasi VM 12 GiB bukan jaminan bila proses lain menghabiskan RAM. Jangan otomatis menghentikan stack/proses milik orang lain. Full identity suite jangan dijalankan bersamaan dengan E2E admin pada database yang sama karena fixture last-admin mengubah role secara sementara dan memulihkannya.

Jika node dikarantina karena worker mati mendadak: hentikan seluruh coordinator/parser container yang memakai `PARSER_NODE_ID` dan Redis prefix yang sama; pastikan tidak ada parser/descendant masih hidup. Baru operator boleh membersihkan key node tepat `PREFIX:parser:leases:NODE`, `PREFIX:parser:memory:NODE`, `PREFIX:parser:heavy:NODE`, lalu restart parser. Pertahankan counter `PREFIX:parser:fence:NODE` dan seluruh checkpoint/reservation/history. Jangan membersihkan lease hanya karena expired, jangan `FLUSHDB`, dan jangan membuka node sebelum kematian proses terbukti. CLI rekonsiliasi otomatis/stress recovery lengkap milik B3.
