Tanggal catatan: 20 Oktober 2026 (Asia/Jakarta). Baseline parent revision: `285eaca`; source B0/B1 dan handover ini termasuk versi branch `development`.

**Status: B1 parsial; gate belum lengkap.** Provisioning sintetis, konteks manual, konflik KK/RPP, approval immutable, dan parsing native DOCX teruji. Pengukuran worker 20 Oktober menunjukkan MemAvailable 8,364,532 kB (sekitar 7,98 GiB), masih di bawah syarat host admission profil Docling sebesar 9 GiB (8 GiB profil + 1 GiB headroom). B2 belum dimulai.

## Cakupan yang tersedia

- Migration `0002_b1_identity_context.py` menambah konteks berversi, konflik, learning outcomes, private file assets, normative links, parse artifacts/checkpoints, processing reservations, source units dan evidence items. PostgreSQL menolak mutasi konteks setelah approval; worker tetap tidak memperoleh hak approval.
- Admin dapat memprovisi akun sintetis, mengelola metadata course dan roster minimal. Akses akademik tetap memerlukan enrollment course; admin tanpa enrollment tidak dapat membaca konteks.
- Dosen dapat membuat konteks manual atau dari sumber KK/RPP tervalidasi, meninjau kandidat dengan source hash/anchor, menyelesaikan konflik dengan alasan, lalu mengesahkan ContextVersion immutable. CPMK kosong sah sebagai `not_provided`.
- Upload privat memeriksa tipe, ukuran, nama, hash dan kontainer. Worker menggunakan storage S3Mock privat, antrean parser, retry cap, admission, checkpoint dan child isolation. Jalur `native_ooxml_v1` benar-benar memparse DOCX sintetis dan menyimpan evidence/anchor.
- Provider tetap `mock`; tidak ada call live, biaya eksternal, atau data mahasiswa nyata.

## Batas verifikasi dan pekerjaan berikutnya

- Jalur parser yang benar-benar dijalankan: DOCX dengan profil native OOXML. PDF, JPG, JPEG, dan PNG menggunakan profil Docling berat dan belum diuji. MemAvailable worker pada 20 Oktober `8,364,532 kB` (sekitar `7.98 GiB`), di bawah kebutuhan host admission `9 GiB`; unit test membuktikan lease ditolak sebelum akses Redis ketika kapasitas host/container tidak cukup. Manual context tetap tersedia.
- PDF/image anchors, OCR, encrypted/oversize PDF behavior, image bomb runtime, OOM/timeout injection, retry recovery, overlap/fencing stress, dan checkpoint reuse belum diverifikasi. Jangan mencatat AC parser lintas format sebagai lulus.
- E2E membuktikan pembatasan admin terhadap context, tetapi tidak mencakup revocation enrollment/session pada tab terbuka, seluruh objek/vector/render, atau semua jalur foreign-source/concurrent revision.
- Tidak ada group assignment API pada tahap ini; kontraknya menunggu assignment B2. Submission namespace, XLSX, viewer lengkap, historical roster snapshot dan benchmark parser menyeluruh menunggu B3.
- Tidak ada AI provider call. Dokumen hanya menghasilkan usulan lokal berlabel dari teks DOCX; live inference memerlukan guard finansial yang belum diaktifkan.

## Handover

### Langkah lanjutan untuk agent berikutnya

1. Baca dokumen B1 ini, `docs/implementation/B1-identitas-dan-konteks.md`, dan `requirements_traceability.md`. Lanjutkan hanya B1; jangan mulai B2.
2. Ukur ulang kapasitas di mesin tujuan:

   ```powershell
   docker compose exec -T parser-worker grep MemAvailable /proc/meminfo
   docker compose exec -T parser-worker cat /sys/fs/cgroup/memory.max
   docker compose exec -T parser-worker cat /sys/fs/cgroup/memory.current
   ```

   Profil Docling hanya boleh diantrekan jika host `MemAvailable` sekurangnya 9 GiB dan sisa cgroup sekurangnya 8 GiB. Nilai yang lebih tinggi sejak pemeriksaan sebelumnya tidak otomatis membuktikan parser berhasil.
3. Jika ambang belum terpenuhi, jangan turunkan `PARSER_DOCUMENT_MEMORY_BYTES`/`PARSER_NODE_HEADROOM_BYTES`, jangan bypass admission, dan jangan menyatakan PDF/image lulus. Pindahkan verifikasi runtime ke mesin/runner dengan kapasitas cukup. Jangan menghentikan proses `Code` atau me-restart WSL untuk mengambil RAM: percobaan penghentian proses `Code` sebelumnya menyebabkan VS Code crash, dan WSL menjalankan stack Compose lokal.
4. Dengan ambang terpenuhi, siapkan fixture sintetis PDF, JPG, JPEG, dan PNG; uji alur upload → worker Docling → source units/evidence/anchors melalui stack Compose nyata. Lengkapi OCR/rotasi, PDF encrypted/oversize, image bomb, kegagalan/timeout/retry, serta checkpoint dan lease yang relevan. Jangan memakai dokumen mahasiswa nyata atau provider live.
5. Jalankan kembali tes unit dan `docker compose --profile test run --build --rm test-runner`. Untuk browser E2E di PowerShell:

   ```powershell
   $env:PLAYWRIGHT_BROWSERS_PATH = Join-Path (Get-Location) '.playwright-browsers'
   $env:ALIGN_WEB_BASE_URL = 'http://localhost:3000'
   corepack pnpm --dir apps/web test:e2e
   ```

   Catat format yang benar-benar diuji, hasil, resource, serta limitasi ke traceability dan handover.
6. Berhenti di B1. Gate tetap parsial bila format/failure mandatory belum memiliki bukti; jangan mulai B2 otomatis.
