## Lanjutkan pengujian

Jangan menyalakan parser dengan mengakali guard. Gunakan host dengan minimal 12 GiB RAM bebas dan Docker Engine dengan minimal 10 GiB, lalu jalankan `scripts/b9/guard.ps1 -HeavyParser` dan `scripts/b9/start.ps1 -IncludeParserWorker`. Jika stack dasar sudah hidup, opsi itu hanya menambahkan parser-worker setelah guard lulus. Setelah job parse selesai, lakukan review manual, approve/publish, launch mahasiswa, tes release/withdrawal/old-vs-new, group mapping dan revocation. Uji pula source berubah saat download, WS token dicabut/function disabled, dan broker/storage failure. Perubahan core `16ad058` sudah tergabung; jalankan regresi jalur terdampak pada branch ini dan ulangi jika ada perubahan development berikutnya.

Stack `align-b9-sandbox` saat ini dibiarkan hidup sesuai permintaan. Periksa status dengan `scripts/b9/readiness.ps1`; `scripts/b9/stop.ps1` mempertahankan named volumes bila operator perlu menghentikannya. Jangan gunakan stack ini untuk Moodle kampus, data riil, grade passback/AGS, deep linking, auto-binding atau posting feedback.
