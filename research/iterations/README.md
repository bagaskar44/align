# Catatan iterasi penelitian

Direktori ini menampung catatan berprovenance; keberadaan template bukan bukti penelitian. Gunakan `../templates/iteration.md` untuk iterasi dan isi dengan partition, hashes, exact commands, numerators/denominators, cost/liability, batas klaim, dan keputusan. Jangan menaruh raw data/secret di sini. Data sintetis dan software tests harus berlabel jelas.

`B8-software-handover.md` mencatat pekerjaan tooling B8. Ia bukan iterasi empiris, tidak menyatakan generalisasi, dan tidak menambah dataset. Data dan decisions institusi yang belum ada tetap pending.
